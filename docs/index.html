01入れ方（3ステップ）

5分もかかりません。管理者の権限もいりません。

1

ファイルをダウンロード

上のボタンを押します。ブラウザが「一般的にダウンロードされていません」などと警告したら、「…」→「保存」→「保持する」を選んでください（作者の署名がない、小さなファイルなので表示されます）。

2

ダウンロードしたファイルをダブルクリック

青い画面が出たら、「詳細情報」を押してから「実行」を押します。

Windows によって PC が保護されました
Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。…
詳細情報
実行実行しない
これは「作者の署名がないファイル」すべてに出る、Windows の標準の確認です。中身はすべて文字で書かれていて、メモ帳で開いて確認できます。
3

質問に［はい］で答える

「インストールしますか？」「自動で起動しますか？」に答えると完了です。最後に壁紙が見つかると、「この壁紙と接続しますか？」と聞かれるので［はい］を押してください。

?
次の壁紙が見つかりました。ヘルパーと接続しますか？
名前: 万能ウィジェット壁紙
自分で入れた「万能ウィジェット壁紙」なら［はい］を押してください。
はい(Y)いいえ(N)
入ったあとは、壁紙の右下にマウスを近づけると出る ⚙ ボタンから設定エディタが開けます。スタートメニューの「万能ウィジェット壁紙」からも開けます。

02ヘルパーなしでも使えます

ヘルパーは「もっと便利にする」ためのもの。入れなくても壁紙はそのまま動きます。

ヘルパーなしで使える
  • 再生中の曲・ジャケット・ビジュアライザー
  • 時計・カレンダー・天気・ToDo など
  • マウスエフェクト・サンプル壁紙
  • 壁紙の中の「かんたん設定」
ヘルパーを入れると増える
  • 再生・スキップ・早送り・音量
  • ショートカットでフォルダを開く
  • PCの状態（CPU・GPUなど）
  • ブラウザの設定エディタ

03安全について

できるだけ危なくないように作っています。

やること
  • メディアキー・音量の操作
  • フォルダと Web サイトを開く
  • PCの状態を読む
  • 設定を保存する
やらないこと
  • プログラムの実行・インストール
  • ファイルの読み取りやアップロード
  • 外部のサーバーへの送信
  • 管理者権限の要求
  • 自分のPCの中（localhost）からの接続だけを受け付けます。
  • 起動のたびに秘密の合言葉を作り、あなたが［はい］で許可した壁紙にだけ渡します。合言葉を持たない命令（ほかのWebサイトなど）はすべて拒否します。
  • 中身はすべてテキストです。WidgetHelperSetup.cmd をメモ帳で開くと、全部読めます。
  • ダウンロードしたファイルが本物か確かめたいときは、PowerShell で Get-FileHash .\WidgetHelperSetup.cmd を実行し、上の SHA256 と同じか比べてください。

04ヘルパーの消し方

いつでも消せます。消しても壁紙はそのまま使えます。

1

スタートメニューから「アンインストール」

スタートメニューの「万能ウィジェット壁紙」→「アンインストール」を選び、［はい］を押します。
（ダウンロードした WidgetHelperSetup.cmd をもう一度開いて、［いいえ］＝アンインストールを選んでも同じです）

2

設定を残すか選ぶ

「エディタで作った設定も消しますか？」で［はい］なら設定も消えます。［いいえ］なら、また入れたときに続きから使えます。

消えるもの：ヘルパー本体、自動起動、スタートメニューの項目、壁紙フォルダに置いた合言葉ファイル（helper\token.js）、（選んだ場合）設定。
壁紙そのものを消すときは、Wallpaper Engine のワークショップで「サブスクライブ解除」してください。
スタートメニューに見つからないとき（手動で消す方法）

① タスクマネージャーの「詳細」タブで、powershell.exe（コマンドラインに media-helper.ps1）と wscript.exe（start-helper.vbs）を終了します。
② エクスプローラーのアドレス欄に次を入力して開き、それぞれ削除します。
　・%LOCALAPPDATA%\UniversalWidgetWallpaper（ヘルパー本体）
　・%APPDATA%\UniversalWidgetWallpaper（設定。残したいときは消さない）
　・shell:startup の中の UniversalWidgetHelper.lnk（自動起動）
　・shell:programs の中の「万能ウィジェット壁紙」フォルダ（スタートメニュー）

05よくある質問

どこに入りますか？

%LOCALAPPDATA%\UniversalWidgetWallpaper に入ります。壁紙のフォルダに置く必要はありません。

消すには？

スタートメニューの「万能ウィジェット壁紙」→「アンインストール」を選ぶだけです。くわしくは上の 「04 ヘルパーの消し方」 をご覧ください。

「接続しますか？」で［いいえ］を押してしまいました

スタートメニューの「アンインストール」をしてから、もう一度入れ直すと再び聞かれます。

ZIP 版の使い方は？

ZIP をダブルクリックで開いて、中の WidgetHelperSetup.cmd をダブルクリックしてください。展開しなくても動きます。

動かないときは？

スタートメニューの「万能ウィジェット壁紙」→「ヘルパーを起動する」を試してください。Wallpaper Engine の設定で「メディア連携」がオンになっているかも確認してください。
