# 万能ウィジェット壁紙

Wallpaper Engine 用の多機能 Web 壁紙です。再生中の曲、時計、カレンダー、天気、ショートカットなどのウィジェットを、好きな場所に並べられます。

![万能ウィジェット壁紙](docs/preview.gif)

**▶ [壁紙本体（Steam ワークショップ）](https://steamcommunity.com/sharedfiles/filedetails/?id=3835840526)**　・　**[操作ヘルパーの配布ページ](https://sora2424.github.io/universal-widget-wallpaper/)**　・　[不具合の報告](https://github.com/sora2424/universal-widget-wallpaper/issues)

> 壁紙本体は **Steam ワークショップ（Wallpaper Engine）でのみ配布**しています。
> このリポジトリにあるのは、壁紙をもっと便利にする「操作ヘルパー」とその配布ページです。

## できること

| 分類 | 内容 |
|---|---|
| 💎 テーマ | 専用テーマ5種 — **翠晶の庭 / Crystal Garden**（標準）・**蒼薔薇の水底 / Azure Rose**・**白曜駅 / Hakuyou Station**・**紫刃の鬼姫 / Violet Blade**・**月下のネオン都市 / Neon Moon City**。テーマごとに動く背景とウィジェットのデザインが変わります |
| 🎵 音楽 | 再生中の曲（Spotify など）・ジャケット・再生バー・ビジュアライザー。ヘルパーがあれば 再生 / スキップ / 早送り / 音量 も |
| 🕒 時間 | 時刻・日付・カレンダー（日本の祝日つき。下に ToDo や付箋メモ）・世界時計・カウントダウン・集中タイマー / ふつうのタイマー（1分単位、終わると音と光でお知らせ）・予定（壁紙から追加、Excel で書き出し／読み込み） |
| 🌤 情報 | 天気（地名 / 緯度経度 / 現在地）・PCの状態（CPU・GPU・メモリ・ドライブ・通信） |
| 🚀 便利 | ショートカット（フォルダ・サイト、最大24個）・ToDo・モニター（PC の動画をループ再生）・縦書きのひとこと・好きな文字（最大6個。横書き / 縦書き、流れる・波・ネオンなど11種類の動き） |
| 🧩 自由度 | ウィジェットはドラッグで移動、サイズ変更、パーツごとに表示 / 非表示。**配置モード**でブロック（マス目）配置 / 自由配置を選べ、大きさもそろえられます。壁紙の中の「かんたん設定」とブラウザの設定エディタ |

## 使い方

### 1. 壁紙を入れる
[Steam ワークショップの作品ページ](https://steamcommunity.com/sharedfiles/filedetails/?id=3835840526) を開いて、**サブスクライブ** してください（Wallpaper Engine の「ワークショップ」で「ウィジェット壁紙」を検索しても見つかります）。

Wallpaper Engine の設定で **「メディア連携」をオン**にしてください（曲の表示に必要です）。
右下にマウスを近づけると出る ⚙ ボタンで、設定パネルが開きます。

### 2. 操作ヘルパーを入れる（任意）
再生・早送り・音量、フォルダを開く、PCの状態、ブラウザの設定エディタが使えるようになります。
設定エディタでは、Wallpaper Engine が今表示している壁紙を「実際の画面」としてそのまま見ながら設定できます（v1.5 から）。「🎨 見た目」から、ダーク／ライト（Windows に合わせる自動も）、デザイン（ノート・シンプル・くっきり）、アクセント色、配置（標準・プレビュー大・設定を広く）、文字の大きさを選べます。ウィンドウの幅に合わせて並びも自動で変わります（v1.6 から）。配置モードの間は、デスクトップのアイコンを一時的に隠して、ドラッグで選択範囲が出ないようにします（終わると元に戻ります）。
ワークショップにはプログラムを入れられないため、ここで配布しています。
ワークショップ版の壁紙には、このヘルパーの案内やリンクは入っていません。入れるとすぐに、壁紙の操作ボタン・音量バー・フォルダのショートカット・PCの状態・予定ノートが使えるようになります（壁紙側の設定は不要です）。

1. [配布ページ](https://sora2424.github.io/universal-widget-wallpaper/) から `WidgetHelperSetup.cmd` をダウンロード
2. ダブルクリック（青い警告が出たら「詳細情報」→「実行」）
3. 質問に［はい］で答える（「この壁紙と接続しますか？」も［はい］）

**ZIP の展開も、置き場所の指定もいりません。** 管理者権限も不要です。

### カレンダーの予定と Excel
- 壁紙のカレンダーで日付を押すと、その日の予定が出ます。「＋」で種類と時刻（開始と終了。終了はなくても OK）を選ぶだけで追加でき、「✎」で文章を書ける**予定ノート**（ブラウザ）が開きます。予定は「10:00–11:30」のように開始と終了の時刻を決められます（v1.6 から）。
- 予定ノートでは、**Excel（.xlsx）**・カレンダー（.ics。Google カレンダー・Outlook 用）・.json に書き出し／読み込みができます。Excel は関数入りの予定表と月間カレンダーになっていて、編集して読み込めば戻せます。
- **保存場所**：予定は `%APPDATA%\UniversalWidgetWallpaper\events.json`。変えるたびに、その日の最初の状態が自動でバックアップされます（30日分。場所は予定ノートで好きなフォルダに変えられます）。
- **プライバシー**：予定はこの PC の中だけに保存し、インターネットには送りません。暗号化はしていないので、**パスワード・住所・電話番号などの個人情報は書かないでください**。

### 操作ヘルパーを更新する
1. [配布ページ](https://sora2424.github.io/universal-widget-wallpaper/) から最新の `WidgetHelperSetup.cmd` をダウンロードして、ダブルクリック
2. 「すでに入っています」と出たら［はい］（入れ直す）を選ぶ

設定・予定・バックアップはそのまま残ります。

- **今の版の確かめ方**：設定エディタ（スタートメニュー「万能ウィジェット壁紙」→「設定エディタを開く」）の左上に「ヘルパー v1.4」のように表示されます。表示がない場合は v1.3 以前です。
- **v1.4 からは**、設定エディタを開いたときに新しい版があれば、画面の上でお知らせします（GitHub に最新版の番号を1日1回まで問い合わせるだけで、ほかには何も送りません）。
- **v1.3 以前を使っている方へ**：新しい版のお知らせが出ないので、一度だけ上の手順で入れ直してください。新しいワークショップの作品ページ（2026年11月6日に公開）の壁紙と、確認なしでつながるようになります。

### 3. 操作ヘルパーを消す
1. スタートメニュー「万能ウィジェット壁紙」→「アンインストール」を選び、［はい］
   （`WidgetHelperSetup.cmd` をもう一度開いて［いいえ］＝アンインストール を選んでも同じです）
2. 「エディタで作った設定も消しますか？」で、消すなら［はい］、残すなら［いいえ］

ヘルパー本体・自動起動・スタートメニューの項目・壁紙フォルダに置いた合言葉ファイル（`helper\token.js`）が消えます。壁紙はそのまま使えます。
壁紙そのものを消すときは、ワークショップで「サブスクライブ解除」してください。

<details><summary>スタートメニューに見つからないとき（手動で消す方法）</summary>

1. タスクマネージャーの「詳細」タブで、`powershell.exe`（コマンドラインに media-helper.ps1）と `wscript.exe`（start-helper.vbs）を終了
2. エクスプローラーのアドレス欄に入力して開き、削除
   - `%LOCALAPPDATA%\UniversalWidgetWallpaper`（ヘルパー本体）
   - `%APPDATA%\UniversalWidgetWallpaper`（設定。残したいときは消さない）
   - `shell:startup` の中の `UniversalWidgetHelper.lnk`（自動起動）
   - `shell:programs` の中の「万能ウィジェット壁紙」フォルダ（スタートメニュー）

</details>

## 安全について

ヘルパーは自分の PC の中だけで動き、**あなたが許可した壁紙以外からの命令はすべて拒否**します。
プログラムの実行やファイルの読み取りはできません。くわしくは [SECURITY.md](SECURITY.md) をご覧ください（残っているリスクも正直に書いています）。
ヘルパーのプログラムはすべてこのリポジトリで公開しているので、中身を確認できます。

## フォルダの中身

```
helper/      操作ヘルパー（PowerShell）
  media-helper.ps1   ヘルパー本体
  editor.html        ブラウザの設定エディタ
  monitor.html       旧モニター用のページ（今のワークショップ版では使いません）
  setup-template.ps1 インストーラーのひな形
  start-helper.vbs   ヘルパーを画面に出さずに起動する小さなスクリプト
docs/        配布ページ（GitHub Pages）とインストーラー
tools/
  build-setup.ps1    helper/ からインストーラー（WidgetHelperSetup.cmd）を作るスクリプト
```
